# TareaSOLID-1
Que es el princio SOLID abierto y cerrado y como lo podemos ver en este codigo?
el principio de abierto y cerrado como el profe nos lo explico dice que una clase debe de estar abierta para la extension y cerrada para la modificacion, esto en base al ejemplo del codigo se podria explicar de la siguiente manera. 
Tenemos una clase padre de Producto el cual tiene dos clases hijas, la digital y la fisica, el principio dice que le podemos agregar funciones para ampliar la funcionalidad del programa pero esta cerrado para modificar el codigo, osea que mientras creemos algun objeto debe de ser imposible modificar una clase ya que sino se romperia el principio
